任务漂移对专家缓存的影响

汇报人：刘  |  日期：2026-08-28  |  研究生组会

核心问题：大型混合专家（MoE）模型在 GPU 显存受限的 offload 部署中， 仅缓存少量激活专家。当推理任务从任务 A（如代码执行）切换到任务 B（如知识问答）时， 频率型缓存（LFU）被「陈旧 A 频率」毒化；而近性型缓存（LRU）对此近乎免疫。 本工作系统量化该「漂移惩罚」，并将其与真机延迟代价锚定。

汇报结构
  • 背景与动机——offload 代价、LRU vs LFU
  • 证据一——热专家分布跨任务近乎不重叠（分布直证）
  • 证据二——LFU 被毒化、LRU 免疫（漂移分量 D）
  • 证据三——5 模型跨粒度一致（容量规律）
  • 证据四——真机 ρ 实测与端到端延迟放大
  • 综合结论与展望

Slide 1背景：为什么要缓存专家？

MoE 每层有 N 个专家（如 Qwen1.5-MoE：N=60，每 token 激活 top-k=4）， 全量权重无法常驻 GPU 显存 → 仅保留缓存容量 C 个专家在 GPU，其余存 CPU/SSD。

策略驱逐规则特点漂移敏感性
LRU（近性）最久未使用自然跟随当前任务近乎免疫
LFU（频率）历史累计频率最低保留历史高频专家被陈旧 A 频率钉住
核心假设：任务切换（A→B）使 A 的历史频率统计过期—— LFU 被迫保留 B 用不上的 A 专家，命中率下降；LRU 因 B 不访问 A 专家而自然冲刷，几乎无损。

漂移分量 D（量化「漂移专门惩罚 LFU」的幅度）：

D = (LRU − LFU)warm − (LRU − LFU)cold  ≈  LFUcold − LFUwarm
（LRU warm ≈ cold 因 LRU 近免疫，故 D 主要来自 LFU 被毒化的部分）

D > 0 = 漂移专门打击频率缓存；D = 0 = 两策略受漂移影响相同。

Slide 2证据一：热专家分布跨任务近乎不重叠

方法：对任务 A（livecodebench，300 条）和任务 B（mmlu 全 57 科，1710 条）， 分别取不相交子集，计算 top-S 热专家的 Jaccard 相似系数。

结论：同任务热专家高度稳定（J=0.51–0.87）， 跨任务骤降至 J=0.07–0.16（约 95% 的 livecodebench 热专家在 mmlu 中不是热专家）。 这是漂移存在的分布层面直接证据，不依赖任何缓存仿真假设，最为可靠。

注：within-mmlu 基线（0.51）低于 within-lcb（0.72），反映 mmlu 57 科内部本身异质—— 即便同标签「mmlu」内不同学科间也有显著专家漂移。

Slide 3证据二：LFU 被毒化，LRU 近免疫

Slide 5证据四：真机 ρ 实测与端到端延迟放大

将证据二/三的 miss 率差通过代价模型翻译为端到端延迟倍数，并用真机（A100-80GB-PCIe）实测 ρ 锚定。

延迟倍数（vs LRU）= (1 + ms·ρ) / (1 + mlru·ρ)， ρ→∞ 饱和于 ms/mlru（miss 率比）。 ρ = 单次专家 miss 延迟 / 单次专家计算延迟（无量纲）。

物理自洽：延迟代价最高的 Llama4（top-1，单专家最大 240 MB，PCIe 取数最久） 恰好 ρ 也最高（65–98）——同一物理根因（大专家 = 高计算承载 = 高搬运代价）， motivation 在最坏情况下自我强化。
ρ 结论：实测全谱 [22, 312] 落在饱和平台（≥25）内； SSD offload 或边缘/消费级硬件只会使 ρ 更大，代价更高。

诚实限定（避免过度声明）

  • 57 科 B 下 D 无 per-C 统计显著（NBOOT=1000 稳定结果）—— 效应真实但被任务异质性稀释，功效不足非效应为零。
  • 「D 随任务连贯度缩放」未通过——MMLU 即使同域科目， 科目间热专家两两 Jaccard 仅 0.21，构造不出足够连贯度对比； 稀疏采样的 COHERENT-12 分离是小样本假象（密集补采后 COHERENT≈DIVERSE）。
  • 论文可写强度：「漂移在分布层面确凿存在，系统性惩罚 LFU、LRU 免疫、随容量单调； 端到端延迟放大 1.33–2.05× 已真机锚定」。
